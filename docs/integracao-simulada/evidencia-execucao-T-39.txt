#   1. Cancelamento de venda Pendente -> 200 {status:"Cancelada"}.

#   3. Cancelamento de venda Quitada sem motivo -> 409 {erro:{codigo:"MOTIVO_OBRIGATORIO"}} (D-06).
#   4. Reenvio após timeout (idempotência, P-2): mesmo payload do cenário 1 reenviado sobre a
#      venda já Cancelada -> mesmo resultado (200 Cancelada), contagem de VendaHistorico
#      confirmada inalterada por consulta direta ao banco (antes/depois do reenvio).
#   5a. Erro 400: payload inválido (vendaId ausente) -> {erro:{codigo:"PAYLOAD_INVALIDO"}}.
#   5b. Erro 401: sem X-Api-Key -> {erro:{codigo:"NAO_AUTORIZADO"}}.
#   5c. Erro 401: X-Api-Key errada -> {erro:{codigo:"NAO_AUTORIZADO"}}, corpo idêntico ao 5b
#       (nenhuma distinção revelada ao chamador, T-35).
#

# Venda desconhecida (cenário 2) não é semeada — o próprio harness a referencia sem que ela exista.
